# Slack web app: layout and features (read-only tour, Oct 2026)

Observed by opening menus and views in a logged-in free-plan workspace. No content was posted.
Used as a feature checklist for Relay; no Slack code, assets or styles were copied.

## Window chrome
- Top bar: back / forward / history, workspace-wide search ("Search <workspace>"), assistant button, help.
- Left rail: workspace switcher (workspace tile, "Add workspaces", "Switch workspaces"), Home, DMs, Activity (badge), More (Files, Agents & tools, Customize navigation bar), Admin, "+" create button, own avatar with status.
- Banner at the bottom: "needs your permission to enable notifications" with an Enable link.

## Workspace menu (click the workspace name)
Invite people, Preferences, Tools & settings, Open the desktop app, Get the mobile app, Sign out.

## Sidebar
- Header: workspace name with caret, "Manage my sidebar" (Filter and sort, Create a section, Clean up your channel list, Edit defaults), New message.
- Items: Huddles, Directories, a seasonal promo, Starred ("Drag and drop important stuff here"), Channels (+ Add channels), Direct messages (+ Invite people), Apps (+ Connect apps).

## Channel header
- Star channel, channel name with edit pencil, channel details.
- Right: Invite teammates, Start huddle (with menu: Start Huddle, Copy huddle link), Edit notifications (All new posts, Just mentions, Mute and hide, More options), Search in channel, More channel actions.
- Tabs: Messages, Add canvas, "+" add tab (Canvas, Link, Folder, List, Workflow, Templates, Customize tabs).
- Channel details dialog: About, Members, Agents & apps, Automations, Tabs, Settings, Leave channel.

## Empty channel
Onboarding cards: Start from a template, Connect your apps, Invite teammates. Day divider with "Jump to date".

## Composer
- Formatting bar: Bold, Italic, Underline, Strikethrough, paragraph style, Link, numbered and bulleted lists, quote, code, code block.
- Bottom: "+" attach (File, List, Text snippet, Workflow, Upload from your computer), Aa (toggle formatting), emoji, mention (@channel, @here, people), video clip (camera, screen share, effects), audio clip, slash shortcuts, send with schedule caret.

## Views
- Activity: tabs All, DMs, Mentions, Threads; Unreads toggle, filters, mark as read, Detailed/Dense density.
- DMs: list of direct messages with Unreads filter and New message.

## Preferences sections
Availability, Notifications, Navigation, Home, Appearance, Messages & media, Language & region, Accessibility, Mark as read, Audio & video, Connected accounts.
